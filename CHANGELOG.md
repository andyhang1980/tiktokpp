## TikTokPP Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

### [1.1.0] - 2025-07-12

#### Added
- GPS spoofing support
- Auto comment translation
- Always-visible video progress bar
- Author IP location display
- Long video duration filter
- Views/likes metric filter
- Offline cold cache restriction toggle
- Page element purification (31 options)
- Media directory customization
- Multi-language support (English, Chinese)
- Playback speed control

#### Changed
- Migrated to libxposed API
- Improved settings UI with navigation rail

#### Fixed
- Loop prevention stability
- Download restriction bypass

### [1.0.0] - 2025-06-01

#### Added
- Initial release
- Region spoofing
- Language/timezone spoofing
- Download restriction removal
- Feed content filtering
- Page purification
- Duet/stitch permission bypass
- Startup login skip
- TikTok cache clearing
